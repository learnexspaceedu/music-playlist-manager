🎵 Music Playlist Manager
Mini Project — JavaScript Foundation
Difficulty: Beginner → Intermediate
Technologies: HTML, CSS, JavaScript
Main focus: JavaScript logic, arrays, objects, functions, callbacks, array methods, and basic DOM

1. Project Overview
   What are we building?
   A simple music playlist manager where users can:
   Add songs to their playlist.
   Search songs by title or artist.
   Remove songs from their playlist.
   The UI is already prepared. Students will mainly work with JavaScript logic.
   Final UI
   The application contains:
   Header
   Playlist statistics
   Add Song form
   Search input
   Playlist
   Empty state
   Remove buttons
