# 🎵 Music Playlist Manager

A beginner-friendly JavaScript mini project for practicing fundamental JavaScript concepts through a simple music playlist application.

> **Course:** JavaScript Foundation  
> **Difficulty:** Beginner → Intermediate  
> **Technologies:** HTML, CSS, JavaScript

## 📌 Project Overview

### What Are We Building?

The **Music Playlist Manager** is a simple web application that allows users to manage their music playlists.

Users can:

- ➕ Add new songs to the playlist.
- 🔍 Search for songs by title or artist name.
- 🗑️ Remove songs from the playlist.

The HTML and CSS UI is already prepared. Students will mainly focus on implementing the JavaScript logic and making the application functional.

## 🖥️ Application Features

The prepared UI includes:

- Header
- Playlist statistics
- Add Song form
- Search input
- Song playlist
- Empty state
- Remove buttons

## 🛠️ Technologies & Concepts

### Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)

### JavaScript Concepts

Through this project, students will practice:

- Variables and data types
- Objects and arrays
- Functions and callbacks
- Array methods
- DOM manipulation
- Event handling
- Form input and validation
- Rendering dynamic content

## 🚀 Project Challenges

Complete the following three challenges to make the application fully functional.

### 🟣 Challenge 01 — Add a Song

**Goal:** Make the Add Song form work.

Students need to implement the logic to:

1. Get values from the form.
2. Validate the input fields.
3. Create a song object.
4. Add the song to the playlist array.
5. Render the updated playlist.

### 🟠 Challenge 02 — Search the Playlist

**Goal:** Make the search box work.

Students need to implement the search functionality to:

1. Get the search input value.
2. Search songs by title or artist name.
3. Display only the matching songs.
4. Update the displayed results when the search input changes.

### 🟢 Challenge 03 — Remove a Song

**Goal:** Make the Remove button work.

Students need to implement the logic to:

1. Identify the selected song.
2. Remove the song from the playlist array.
3. Render the updated playlist.
4. Update the playlist statistics.

## 📥 Getting Started

### 1. Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/learnexspaceedu/music-playlist-manager.git
```

### 2. Open the Project

Navigate to the project folder:

```bash
cd music-playlist-manager
```

### 3. Run the Application

Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.
